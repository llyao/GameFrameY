GameFrameY 架构地图

GameFrameX + YooAsset + Luban + VContainer 的游戏客户端框架单仓：全部第三方依赖以源码（embedded package）随仓库分发，自研层 GameFrameY.Core 提供模块管理 + 服务发现，服务端为 GameFrameX.Server 快照（.NET 10）。本系列逐包拆解每个模块的细节、API 与用法。

Unity 2022.3 LTS 20 个 vendored 包 · 零第三方 registry 服务端 .NET 10 · MongoDB 配置 Luban v5.1 一份定义双端生成

1 这套框架是什么

一句话：用 VContainer 做依赖注入脊柱，把 GameFrameX 组件族（资源 / 场景 / UI / 事件 / 网络）统一装进"模块"体系，再以 Luban 打通双端配置、以 YooAsset 打通资源管线。仓库分四块：

📦 Client/ — Unity 工程

全部第三方包 vendored 在 Packages/（embedded 优先于 registry）；业务代码在 Assets/GameFrameY/；打开 Boot.unity 直接 Play。

🗂 Config/ — Luban 配置仓

一份定义（Defines/schema.xml）+ 数据（Datas/*.json），双端生成：客户端 cfg 命名空间、服务端 GameFrameY.Config；生成器 v5.1.0 源码也在仓内。

🖥 Server/ — 服务端快照

GameFrameX.Server（.NET 10，Actor/TPL DataFlow + SuperSocket + MongoDB）+ 我们新增的 Server/Config 配置库。来源与同步见 Server/PROVENANCE.md。

📡 Protobuf/ — 双端协议

proto3 协议约定（消息 ID = (moduleId << 16) + seqId），客户端 NetworkComponent 与服务端共用一份 proto（生成工具接入属于后续基建）。

三个核心概念（自研层的全部）
  • 模块：[GameModule("Name", Dependencies = new[]{"Asset"}, Startup = ModuleStartup.Deferred)] 标记的类，自动发现 → 依赖拓扑排序 → VContainer 线性子作用域装配；依赖声明负责排序与存在性校验。
  • 服务：优先构造注入；IServiceRegistry 提供中央登记表 + 根作用域兜底、登记事件 + WaitServiceAsync（未就绪先等待）。
  • 流程：启动流程 Launch → Patch → LoadConfig → EnterGame 四步，状态依次推进到 Ready；异常进入 Failed，EnterGame 装配 Deferred 业务模块后只广播一次 GameFrameY.GameReady。

5 客户端启动时序（点步骤展开细节）

从按下 Play 到 GameReady，一共八步。核心编排者是自研的 GameFrameYGameLauncher（VContainer EntryPoint），它要等 GameFrameX 组件宿主就绪后才开始装配模块、启动流程。

STEPPER启动时序 · 共 8 步

6 快速开始

  1. Unity Hub → Open → D:\GameFrameY\Client（无需任何第三方 registry，全部包已 vendored）。
  2. 打开 Assets/Scenes/Boot.unity → Play（确认它是 Build Settings 第 0 个场景）。
  3. Console 过滤 [GameFrameY]，看到下面这段日志即冒烟通过：
[GameFrameY] GameFrameX 组件就绪，开始装配 Bootstrap 模块...
[GameFrameY] 模块就绪: Event (EventModule) ...（六桥接模块）
[GameFrameY] 启动流程已开始（Launch → Patch → LoadConfig → EnterGame）
[GameFrameY] 资源包初始化完成
[GameFrameY] Luban 配置加载完成：TbItem 6 条，TbServerList 3 条
[GameFrameY] 模块就绪: Demo (DemoModule)
[GameFrameY] [Demo] Hello, GameFrameY! 模块装配 → 服务发现 → 解析 全链路 OK
[GameFrameY] GameFrameY 启动流程完成（GameReady）
[GameFrameY] [Demo] Tick 心跳 #1（每 3 秒一条）

改配置 = 改 Config/Defines/schema.xml（结构）+ Config/Datas/*.json（数据）→ 跑生成脚本 → 回 Unity 直接生效。需要 .NET SDK 8+（生成器已随仓构建）。

cd Config
./gen-client.sh    # 生成客户端 cfg 代码 + bytes（Windows 用 gen-client.bat）
./gen-server.sh    # 生成服务端 GameFrameY.Config 代码 + bytes
产物：代码 → Client/Assets/GameFrameY/Config/Generate；bytes → Client/Assets/Bundles/Config（YooAsset 收集）

细节见 第 07 章 · Luban 配置管线。

docker compose up -d                 # 根目录：起 MongoDB（mongo:7）
cd Server
dotnet run --project GameFrameX.Launcher   # .NET 10 SDK
# 默认端口：TCP 29100 / HTTP 28080 / WebSocket 29110 / Metrics 29090

健康检查 http://localhost:29090/health，指标 /metrics。我们自己的服务端配置库单独可编译：cd Server/Config && dotnet build。细节见 第 08 章。
