CH.04 · UI 与场景

UI（核心 + UGUI 适配）与场景管理

UI 是经典的双包结构：com.gameframex.unity.ui（后端无关抽象：UIGroup 层级 / IUIForm 生命周期 / 实例池）+ com.gameframex.unity.ui.ugui（UGUI 实现：prefab 实例化 / 组 Canvas / Z 偏移层级）。场景包 scene 把 YooAsset 的 SceneHandle 包装成按路径的加载/卸载/激活顺序管理。

ui 3.0.1 · ui.ugui 2.7.2 · scene 3.0.2 UIComponent Order = 1400（最晚挂载） 默认 18 个 UIGroup

4 IUIForm：界面的完整生命周期

阶段方法说明
创建OnAwake()组件首次挂到 prefab 实例时（IsAwake 标记防重入）
Init(serialId, assetPath, group, onInitAction, pauseCoveredUIForm, isNewInstance, userData, recycleInterval, isFullScreen)框架回填元信息
OnInit() → OnOpen(object userData)打开（userData 透传 OpenAsync 参数）
绑定BindEvent() / LoadData()事件绑定与数据装载（推荐在这里读配置表/发请求）
UpdateLocalization()本地化刷新（语言切换事件时也会被调，见 06 章）
显隐Show(handler, complete) / Hide(handler, complete) / OnPause / OnResume / OnCover / OnReveal / OnRefocus(userData)被覆盖=Pause+Cover，露出来=Resume+Reveal；同界面再 Open 会 Refocus 而不是重开
每帧OnUpdate(elapse, realElapse)UIComponent 驱动
关闭OnClose(isShutdown, userData)isShutdown=true 表示框架关闭而非正常关闭
回收OnRecycle() / RecycleInterval / IsDisableRecycling / IsCanRecycle实例池自动回收策略（UIOptions.InstanceExpireTime=60s 等四参数）

常用属性：SerialId / FullName / UIFormAssetName / Handle / Visible / UIGroup / DepthInUIGroup / PauseCoveredUIForm / EnableShowAnimation + ShowAnimationName / EnableHideAnimation + HideAnimationName。UGUI 后端的界面基类是 UGUI : UIForm（注意类名就叫 UGUI），Visible 映射 gameObject.activeSelf，MakeFullScreen() 拉满 RectTransform。

6 UGUI 适配的三个关键实现

// ① 加载与实例化（UIManager.Open.cs）：Resources / YooAsset 双路径
if (uiFormAssetPath.IndexOf(Utility.Asset.Path.BundlesDirectoryName) < 0)
    original = (GameObject)Resources.Load(assetPath);          // Resources 兜底
else {
    var assetHandle = await m_AssetManager.LoadAssetAsync<UnityEngine.Object>(assetPath);
    var gameObject = assetHandle.InstantiateSync();            // ← prefab 实例化点
    openUIFormInfo.SetAssetHandle(assetHandle);                // 句柄由框架持有
}

// ② 归组与特性解析（UGUIFormHelper.CreateUIForm）
var componentType = uiGameObject.GetOrAddComponent(uiFormType); // 把逻辑组件挂上实例
if (uiForm.IsAwake == false) uiForm.OnAwake();
uiTransform.SetParent(helper.transform);                        // helper = 组容器
uiTransform.localScale = Vector3.one;

// ③ 组层级（UGUIUIGroupHelper.SetDepth）
transform.localPosition = new Vector3(0, 0, depth * 1000);       // Z 偏移实现层叠
// 每组 EnsureCanvas：ScreenSpaceCamera Canvas（planeDistance=100, overrideSorting）

三条约束（源码行为）
  • sceneAssetName 必须以 Assets/ 开头、.unity 结尾，否则 ArgumentException。
  • Single 模式会先卸载全部已加载场景（提前占位防重入 + 统一释放旧场景的 YooAsset 引用）；已加载场景重复 Load（Additive）抛异常。
  • YooAsset await 完成可能早于 Unity scene.isLoaded，SetActiveScene 失败时内部协程最多重试 60 帧再激活（别在 Load 返回瞬间就假设 active scene 已切换）。

事件（经事件总线转发）：LoadSceneSuccessEventArgs（含 Duration/UserData）/ LoadSceneFailure / LoadSceneUpdate(Progress) / UnloadSceneSuccess/Failure / ActiveSceneChanged。SceneOptions 两个开关：EnableLoadSceneUpdateEvent（默认 true）、EnableLoadSceneDependencyAssetEvent（依赖资源更新事件，默认 true）。
