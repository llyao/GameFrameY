CH.04 · UI 与场景

UI（核心 + UGUI 适配）与场景管理

UI 是经典的双包结构：com.gameframex.unity.ui（后端无关抽象：UIGroup 层级 / IUIForm 生命周期 / 实例池）+ com.gameframex.unity.ui.ugui（UGUI 实现：prefab 实例化 / 组 Canvas / Z 偏移层级）。场景包 scene 把 YooAsset 的 SceneHandle 包装成按路径的加载/卸载/激活顺序管理。

三条约束（源码行为）
  • sceneAssetName 必须以 Assets/ 开头、.unity 结尾，否则 ArgumentException。
  • Single 模式会先卸载全部已加载场景（提前占位防重入 + 统一释放旧场景的 YooAsset 引用）；已加载场景重复 Load（Additive）抛异常。
  • YooAsset await 完成可能早于 Unity scene.isLoaded，SetActiveScene 失败时内部协程最多重试 60 帧再激活（别在 Load 返回瞬间就假设 active scene 已切换）。

9 内部：加载编排、实例池与组刷新

9.1 打开去重的三个层次

BaseUIManager 用三层手段避免重复开销：① 已打开 → Refocus（不重加载）；② 加载中 → 复用同一个 UIFormLoadingObject.Task（并发 Open 同一界面只付一次加载成本，serialId 由 ++m_Serial 递增）；③ 已回收 → 实例池 Spawn 复用（isNewInstance=false，跳过 OnAwake）。实例池用的是 GameFrameX 的对象池体系——UIComponent.Start 里 SetObjectPoolManager(GameFrameworkEntry.GetModule<IObjectPoolManager>())，参数即 UIOptions 四项：InstanceAutoReleaseInterval=60s / InstanceCapacity=16 / InstanceExpireTime=60s / InstancePriority=0（回收间隔/容量/过期时长/优先级）。

9.2 UIGroup.Refresh：OnPause/OnCover 的真正调用者

public void Refresh()
{
    LinkedListNode<UIFormInfo> current = m_UIFormInfos.First;
    bool pause = m_Pause;      // 组级暂停
    bool cover = false;
    int depth = UIFormCount;   // 组内深度：栈式自上而下

    while (current != null)
    {
        var info = current.Value;
        info.UIForm.OnDepthChanged(Depth, depth--);     // 每次刷新都重算组内深度
        if (pause || cover)
        {
            // 覆盖链：栈顶之下全部 Covered（+暂停条件满足时 Paused）
            // → 依次触发 OnCover / OnPause（是否暂停取决于该界面的 PauseCoveredUIForm）
        }
        else { /* → OnReveal / OnResume */ }
        cover = true;   // 第一个界面之后都算"被覆盖"
        current = current.Next;
    }
}
即 OnPause/OnResume/OnCover/OnReveal 由 UIGroup.Refresh 在 Open/Close/组 Pause 变化时统一重算触发；"界面被谁盖住"不需要手动管理

9.4 UIFormLoadingObject：共享的是任务，不是实例

打开流程中的 UIFormLoadingObject 是一个 ReferencePool 对象，字段只有资源路径、资源名、类型和 Task<IUIForm>。单例模式下，第二个并发打开请求命中同一组字段后直接 await loadingUIForm.Task；加载结束时从 m_LoadingUIForms 移除并归还引用池。

public static UIFormLoadingObject Create(
    string assetPath, string assetName, Type formType, Task<IUIForm> task)
{
    var value = ReferencePool.Acquire<UIFormLoadingObject>();
    value.UIFormAssetPath = assetPath;
    value.UIFormAssetName = assetName;
    value.UIFormType = formType;
    value.Task = task;
    return value;
}

// InnerOpenUIFormAsync：单例模式的并发去重
foreach (var loading in m_LoadingUIForms)
{
    if (loading.UIFormAssetPath == uiFormAssetPath
        && loading.UIFormAssetName == uiFormAssetName
        && loading.UIFormType == uiFormType)
        return await loading.Task;
}

try
{
    return await uiFormTask;
}
finally
{
    if (m_LoadingUIForms.Remove(loadingObject))
        ReferencePool.Release(loadingObject);
}
因此“加载中去重”只共享一次资源加载和一次最终 UI 实例创建；它不是一个可重复 Spawn 的实例句柄。失败、取消或完成都必须经过 finally 清掉 loading 记录，否则同名界面会永久被判定为加载中。

9.5 打开与回收：单实例池化，多实例现建

if (UseSingletonOpenMode(uiFormType))

    if (opened != null)
    {

            uiFormAssetName, uiFormType, pooled.Target,
            pauseCoveredUIForm, false, 0f, userData, isFullScreen);
}

// 加载成功：创建实例对象并登记到 MultiSpawn 池
var instance = UIFormInstanceObject.Create(...);
m_InstancePool.Register(instance, true);
return InternalOpenUIForm(..., instance.Target, ..., true, ...);

// UIManager.RecycleUIForm
uiForm.OnRecycle();
m_InstancePool.Unspawn(uiForm.Handle);
if (isDispose)
    m_InstancePool.ReleaseObject(uiForm.Handle);

源码特意把实例池复用限制在单实例打开模式：这个池是 MultiSpawn 池，多实例界面如果复用仍在使用的同一个 GameObject，会让多个逻辑组件共用同一对象。关闭时先 Unspawn，只有明确销毁时才 ReleaseObject；所以“关闭”不等于“销毁资源”。

生命周期观察点

新加载实例进入 InternalOpenUIForm 时 isNewInstance=true，池中取回的实例传入 false。成功打开的调用顺序是 Init → AddUIForm → OnOpen → BindEvent → LoadData → UpdateLocalization → Show → UIGroup.Refresh；排查界面重复初始化时，应先看它走的是“新建”还是“池复用”分支。

9.6 场景的三张状态表：Loading、Loaded、Unloading

// LoadScene：先拒绝冲突，再写入 Loading 表
if (SceneIsUnloading(sceneAssetName))
    throw new GameFrameworkException("scene is being unloaded");
if (SceneIsLoading(sceneAssetName))
    throw new GameFrameworkException("scene is being loaded");

if (sceneMode == LoadSceneMode.Single)
{
    m_LoadingSceneAssetNames[sceneAssetName] =
        new SceneHandleData(null, userData); // 先占位，防止卸载回调重入
    UnloadAllLoadedScenesInternal();
}
else if (SceneIsLoaded(sceneAssetName))
{
    throw new GameFrameworkException("scene is already loaded");
}

try
{
    var handle = await m_assetManager.LoadSceneAsync(sceneAssetName, sceneMode, true);
    m_LoadingSceneAssetNames[sceneAssetName] =
        new SceneHandleData(handle, userData);
    handle.Completed += OnLoadSceneCompleted;
    return handle;
}
catch
{
    m_LoadingSceneAssetNames.Remove(sceneAssetName);
    throw;
}

// OnLoadSceneCompleted：只有成功才进入 Loaded 表
if (loadSucceed)
    m_LoadedSceneAssetNames.Add(assetPath, sceneOperationHandle);
m_LoadingSceneAssetNames.Remove(assetPath);

UnloadAllLoadedScenesInternal 会先复制并清空 Loaded 表，再逐项处理：Additive 场景调用 handle.UnloadAsync() 并登记到 Unloading 表；被 YooAsset 标记为 main scene 的 Single 场景不能主动 UnloadAsync，由 Unity 加载新 Single 场景时销毁对象，框架只补发成功事件来同步 UI/Scene 状态。

场景句柄的状态变化不是一个布尔值：Loading 防重入，Loaded 才允许正常 Unload，Unloading 防止同名并发操作。Load 失败必须删除 Loading 占位，否则下一次重试会被错误地拦截。
